# Data management

현재 raw/processed 데이터는 반입하지 않았다. 기존 작업공간의 확보 사실과 이 repository의 파일 보유 상태를 구분한다.

- `raw/`: 수집한 원본. 수정하지 않고 출처·수집시각·라이선스·지역·기간·단위를 기록한다.
- `processed/`: 재현 가능한 전처리 결과. UTC·구간 간격·MWh/MW·결측 검사를 기록한다.
- 두 디렉터리의 실제 데이터는 기본 Git 제외다. 공유 방식과 배포 가능 범위는 팀이 정한다.
- 가격은 €/MWh, 작업은 MW, 간격은 시간이다. 비용은 세 항의 곱을 합산한다.
- NASA 일별 관측은 미래 예보가 아니다. LST/UTC 기준을 확인하고 Join한다.
- V2에서는 `issued_at` 이전 이용가능 자료만 사용한다.
